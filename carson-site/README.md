# Carson site

This standalone Next.js product was generated by Stackiln and customised for
Carson, the Oakridge Discord security guard.

Run `pnpm install` and `pnpm dev`, then open http://localhost:3000. Use
`pnpm verify` for typecheck, tests, lint, a static production build and desktop
and mobile browser checks.

Production builds are exported to `apps/web/out` and deployed by the repository
root GitHub Pages workflow. The custom domain is `carson.stackiln.com`.
