# Changelog

All notable changes to Stackiln are documented here. This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html) and the structure of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- MIT licensing and public contribution, conduct, security, support, governance, release, and generated-code guidance.
- GitHub issue forms, pull request guidance, dependency updates, and code ownership.
- Stackiln brand mark and usage guidance.
- A first-class block system with 60 public-site families, four composed page recipes, exact CLI selection, module requirements, generated ownership records, and responsive block foundations.

### Changed

- Renamed Site Factory to Stackiln across the CLI, packages, generated metadata, fixtures, documentation, and verification assets.

## [0.1.0] - 2026-09-19

### Added

- Transactional generator with deterministic plans and managed-file checksums.
- Verified marketing preset and optional accounts module.
- PostgreSQL migrations, browser journeys, and container verification.
