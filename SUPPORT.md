# Support

StackKiln is maintained as an open-source project without a guaranteed response time or service-level agreement.

- Use GitHub Discussions for setup help, design questions, and general usage.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Read the [README](README.md), [architecture](docs/architecture.md), and [roadmap](ROADMAP.md) before asking for support.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

When asking for help, include your operating system, Node and pnpm versions, StackKiln commit or release, the command you ran, the smallest relevant configuration, and complete error output with secrets removed.
