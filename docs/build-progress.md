Status: in progress. The optional `accounts` recipe can be selected with `--module accounts` and composes Better Auth's Drizzle schema and a checked-in migration. The independent `fixtures/generated/accounts` product is included in the root verification gate: install, migrate on PostgreSQL 17, typecheck, lint, build, and desktop/mobile Playwright runs. Browser coverage includes registration, email verification, sign-in, profile update, two-step email change, password change and recovery, session listing and remote revocation, authenticated export, and emailed deletion confirmation. A follow-up `db:generate` must report no schema changes.

Still pending for the Phase 2 gate: separate admin and audit modules, a central permission catalogue, account suspension/bans, queued export/deletion, internal-tool and personal SaaS presets, and cross-account/privilege-escalation coverage beyond the export authorization check. The current export and deletion operations are foundations, not the specified asynchronous lifecycle.

## Decisions

- Plan module ownership and dependency changes before writing.
- Write into a sibling staging directory and rename only after structural checks.
- Track SHA-256 hashes for every managed file.
- Exclude Next.js-owned `next-env.d.ts` from managed checksums because Next rewrites it during dev and build.
